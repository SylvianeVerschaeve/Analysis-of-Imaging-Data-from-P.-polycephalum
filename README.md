This is the GitHub Repository containing scripts used for the analysis of Imaging Data obtained form X-Ray images of Physarum poycephalum. 
The script "macro comparisons.R" contains the analysis of data obtained from the macroplasmodial stages of different strains of P. polycephalum.
The script "Spherical_particles_analysis.R" contains the volume analysis obtained from spherical particles observed at different stages of P. polycephalum.
